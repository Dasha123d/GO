# Лучшие практики squirrel

## 1. Используйте один StatementBuilder для всего приложения

Создайте глобальную переменную:

```go
var PSQL = sq.StatementBuilder.PlaceholderFormat(sq.Dollar)
```
Это гарантирует согласованность плейсхолдеров.

## 2. Не забывайте про `RETURNING` для PostgreSQL
Используйте `Suffix("RETURNING id")` для вставки с возвратом сгенерированного ключа.

## 3. Экранируйте имена таблиц и колонок
Если имена совпадают с ключевыми словами, оборачивайте их в кавычки:
```go
psql.Select("\"user\"").From("\"order\"")
```
## 4. Для динамических запросов используйте накопление условий
Иммутабельные билдеры: каждое `Where`, `Select` возвращает новый билдер — безопасно и удобно.

## 5. Не подставляйте пользовательский ввод напрямую
Всегда используйте плейсхолдеры и `sq.Expr` с аргументами:
```go
// Плохо
psql.Select("*").From("users").Where("name = '" + name + "'")
// Хорошо
psql.Select("*").From("users").Where(sq.Eq{"name": name})
```
## 6. Логируйте сгенерированный SQL
Для отладки и мониторинга оберните вызов `ToSql` в логгер.

## 7. Для сложных агрегатных запросов используйте `sq.Expr`
Не пытайтесь выразить всё через мапы — `Expr` даёт полную гибкость.

## 8. Тестируйте запросы
Создайте unit-тесты, которые проверяют, что сгенерированный SQL и аргументы совпадают с ожидаемыми.

## 9. Используйте транзакции для нескольких связанных операций
squirrel не предоставляет ORM-методов, поэтому управление транзакциями полностью на вас.

## 10. Комбинируйте с `sqlx` для сканирования
squirrel генерирует SQL, а `sqlx` позволяет удобно сканировать результаты в структуры.
