# Лучшие практики использования bun

## 1. Используйте контекст с тайм-аутом

```go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()
```
## 2. Не забывайте про индексы в БД
bun не добавляет индексы автоматически. Создавайте их через миграции.

## 3. Остерегайтесь N+1 запросов
Используйте `Relation()` для eager loading. Проверяйте запросы через `bundebug`.

## 4. Используйте `bun.BaseModel` в модели
Это добавляет встроенные методы `String()`, `TableName()`.

## 5. Для продакшена настраивайте пул соединений
`SetMaxOpenConns`, `SetConnMaxLifetime` обязательны.

## 6. Запускайте миграции отдельно
bun поддерживает миграции через `github.com/uptrace/bun/migrate`. Не используйте `AutoMigrate` в продакшене.

## 7. Используйте сканирование в слайсы, а не циклы
`Scan(ctx, &slice)` делает один запрос. Не вызывайте в цикле `NewSelect`.

## 8. Не храните модель с паролями в открытом виде
Создавайте отдельные структуры для запросов: `UserDTO` без поля `Password`.

## 9. Логируйте только медленные запросы
Можно реализовать `QueryHook`, который выводит запросы дольше порога.

## 10. Тестируйте с реальной БД в Docker
Используйте `testcontainers-go` с PostgreSQL, чтобы тесты были максимально приближены к production.
