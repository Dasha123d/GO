# Совместимость с encoding/json и другими библиотеками

## API совместимость

Сгенерированные структуры реализуют:
- `json.Marshaler` и `json.Unmarshaler` (стандартные интерфейсы), поэтому могут использоваться везде, где ожидается работа с JSON.
- `easyjson.Marshaler` и `easyjson.Unmarshaler` для прямого вызова.

Вы можете просто заменить `json.Marshal` на `easyjson.Marshal`, если работаете с переменной интерфейсного типа. Для конкретных структур удобнее использовать методы `u.MarshalJSON()`.

## Совместимость с другими библиотеками

Gin, Echo, стандартный `http` корректно работают с easyjson, если использовать кастомный рендер или просто передавать сгенерированную структуру в `c.JSON(200, obj)`. Gin вызовет `obj.MarshalJSON()`, который уже сгенерирован.

## Различия

- Кодогенерация обязательна. Без неё структура не получит ускорения и не реализует интерфейсы.
- На этапе разработки нужно не забывать перегенерировать код при изменении модели.
- Некоторые продвинутые возможности `encoding/json` (вроде `,string` для чисел) требуют явной поддержки; easyjson их обрабатывает корректно.

## Обратная сторона

- Увеличение размера бинарного файла (дополнительный код).
- Дополнительный шаг в CI/CD.
- При изменении структуры без перегенерации – падение производительности до стандартной или даже ошибки компиляции.

Чтобы избежать проблем, используйте `go generate` и проверяйте актуальность сгенерированных файлов в CI (например, проверка, что `easyjson -all *.go` не вносит изменений).
