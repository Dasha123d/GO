# Совместимость с encoding/json

## Полная совместимость на уровне API

jsoniter реализует те же интерфейсы:
- `json.Marshal` / `json.Unmarshal`
- `json.Marshaler` / `json.Unmarshaler`
- `json.NewEncoder` / `json.NewDecoder`
- Поддержка тегов `json:"name,omitempty,string"`

## Режимы совместимости

- `ConfigCompatibleWithStandardLibrary` – максимальная совместимость, практически 100%.
- `ConfigFastest` – отключает некоторые проверки ради скорости: игнорирует интерфейс `json.Unmarshaler` у полей, предполагает, что строки в JSON корректные, и т.п.

## Различия с encoding/json

- **Производительность**: в 2–3 раза быстрее.
- **Поведение**: по умолчанию может не сортировать ключи map (отключаемо).
- **Обработка ошибок**: некоторые ошибки могут возникать раньше/позже из-за другого порядка парсинга.

## Миграция

Просто замените импорт и создайте переменную `json`:

```go
import jsoniter "github.com/json-iterator/go"
var json = jsoniter.ConfigCompatibleWithStandardLibrary
```
Весь остальной код менять не нужно. Для полной уверенности используйте эту конфигурацию и прогоните тесты.

## Обратная совместимость
Если вы используете сторонние библиотеки, которые внутри используют `encoding/json`, они не получат ускорения автоматически. Чтобы заменить глобально, можно воспользоваться небезопасным трюком с заменой `encoding/json` через `go:linkname`, но это не рекомендуется. Лучше передавать сконфигурированный API явно.
