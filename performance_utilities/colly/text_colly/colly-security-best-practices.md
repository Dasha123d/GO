# Этика и безопасность Colly: лучшие практики

## 1. Уважайте robots.txt

Не отключайте `IgnoreRobotsTxt` без крайней необходимости. Colly по умолчанию соблюдает правила.

## 2. Ограничивайте частоту запросов

```go
c.Limit(&colly.LimitRule{
    DomainGlob:  "*",
    Delay:       5 * time.Second,
    RandomDelay: 2 * time.Second,
    Parallelism: 1,
})
```
Слишком частые запросы создают избыточную нагрузку и могут привести к блокировке.

## 3. Идентифицируйте своего бота
Установите значимый User-Agent и добавьте страницу с описанием бота:
```go
c.UserAgent = "MyCompanyBot/1.0 (+https://mycompany.com/bot)"
```
Уважайте вебмастеров: дайте возможность связаться с вами.

## 4. Обрабатывайте ошибки и HTTP-статусы
Не считайте любой ответ успешным. Проверяйте статус:
```go
c.OnResponse(func(r *colly.Response) {
    if r.StatusCode >= 500 {
        // возможно, сервер перегружен — сделаем паузу
        time.Sleep(30 * time.Second)
    }
})
```

## 5. Защита от бесконечного обхода
Ограничивайте глубину (`MaxDepth`) и количество страниц через счётчик в глобальной переменной (или через кастомную логику в `OnScraped`).

## 6. Не передавайте конфиденциальные данные
Не отправляйте через краулер пароли, токены, если это не требуется. Храните их в переменных окружения.

## 7. Осторожно с файлами и формами
Не загружайте файлы через краулер, если не уверены в безопасности. Избегайте сабмита форм на внешние ресурсы (CSRF-риски).

## 8. Логируйте, но не раскрывайте
Логируйте ошибки, но не пишите в лог полные URL с параметрами сессии или токенами.

## 9. Используйте прокси при необходимости
Если боитесь блокировки по IP — используйте ротацию прокси через `SetProxyFunc`.

## 10. Соблюдайте законы
Убедитесь, что ваш краулинг соответствует законодательству (GDPR, авторские права, условия использования сайта). Не крадите данные, не нарушайте работу сервисов.
