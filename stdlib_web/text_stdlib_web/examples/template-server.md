# Пример: Сервер с HTML-шаблонами

Файл: `template-server.go`

## Назначение
Демонстрирует использование `html/template` для рендеринга динамического HTML-контента с передачей структуры данных в шаблон.

## Запуск
```bash
go run template-server.go
```
Откройте `http://localhost:8080` в браузере. Вы увидите страницу со списком элементов.
