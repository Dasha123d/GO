# Быстрый старт с Gorilla Mux

## Основная концепция
Gorilla Mux — это мощный роутер и диспетчер HTTP-запросов для Go, построенный на стандартной библиотеке `net/http`. Он реализует интерфейс `http.Handler`, что обеспечивает полную совместимость с экосистемой Go.

## Ключевые особенности
- Сопоставление маршрутов по методу, пути, заголовкам, query-параметрам
- Переменные пути с поддержкой регулярных выражений: `/users/{id:[0-9]+}`
- Подмаршрутизаторы (subrouters) для организации кода
- Именованные маршруты для генерации URL
- Middleware-цепочки через `Use()`
