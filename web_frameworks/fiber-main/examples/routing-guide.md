# Роутинг и параметры URL в Fiber

## Основная концепция
Fiber использует маршрутизатор на основе radix tree для быстрого сопоставления URL. Поддерживаются параметры (`:param`), wildcard (`*`), опциональные параметры (`?`) и группировка маршрутов.

## Ключевые паттерны
- `:name` — обязательный параметр пути
- `:name?` — опциональный параметр (если отсутствует, возвращается `""`)
- `*` — wildcard для захвата остатка пути
- `app.Group("/prefix")` — изоляция маршрутов с общим middleware

## Особенности Fiber v3
- Все обработчики возвращают `error` для единообразной цепочки обработки
- `c.Params()` валиден только внутри текущего хендлера (Zero-Allocation)
- Группы наследуют middleware родительского роутера и могут добавлять свои
