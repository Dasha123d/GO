# Работа с контекстом, JSON и валидацией

## fiber.Ctx
Контекст запроса предоставляет методы для чтения HTTP-данных и формирования ответа. Является переиспользуемым объектом (pool-based) для минимизации аллокаций.

## Парсинг тела запроса
- `c.Bind(&dest)` — автоматический парсинг JSON/XML/Form в Go-структуру
- Структуры должны содержать теги `json:"field_name"`
