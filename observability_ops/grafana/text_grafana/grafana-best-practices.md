# Лучшие практики

## 1. Следите за логами

SDK предоставляет `log.DefaultLogger`. Не используйте `fmt.Println`.

## 2. Кешируйте подключения внутри экземпляра

Храните `*sql.DB` внутри структуры датасорса.

## 3. Используйте контекст

Запросы приходят с `context.Context` — передавайте их в БД.

## 4. Для больших данных используйте потоковые ответы

Можно отправлять данные частями, реализовав `StreamHandler`.

## 5. Валидируйте запросы

Не доверяйте JSON-моделям запросов полностью.

## 6. Используйте `backend.QueryDataRequest` и `Queries`

Можно обрабатывать несколько запросов за раз.

## 7. Сборка и распространение

Собирайте плагин с помощью `mage` или Makefile. Загружайте в Grafana Plugin Catalog.

## 8. Тестирование

Можно тестировать, запуская плагин и Grafana в Docker Compose.
