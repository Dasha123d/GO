# Продвинутая инъекция: Группы и Аннотации

## Проблема
Иногда нужно предоставить несколько реализаций одного интерфейса (например, список всех плагинов или обработчиков) и собрать их в срез.

## Группы значений (`Value Groups`)
Fx позволяет объединять результаты разных конструкторов в одну именованную группу.

### Синтаксис
1. **Производитель (Provider)**:
   Использует `fx.Annotate` с тегом `group:"имя_группы"`.
   ```go
   fx.Provide(
       fx.Annotate(
           NewHandlerA,
           fx.ResultTags(`group:"handlers"`),
       ),
   )
