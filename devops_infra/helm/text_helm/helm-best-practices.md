# Лучшие практики Helm SDK

## 1. Используйте namespace из контекста, не хардкодьте

```go
actionConfig.Init(..., ns, ...)
```
## 2. Не забывайте про контекст
Для долгих операций используйте `context.Background()` с таймаутом через `install.Timeout`.

## 3. Кешируйте action.Configuration
Создавайте один раз и переиспользуйте, он потокобезопасен.

## 4. Всегда указывайте драйвер хранения
* `"secret"` — по умолчанию, как в Helm CLI.
* `"configmap"` — тоже допустимо.
* `"memory"` — для тестов.

## 5. Освобождайте временные файлы
При загрузке чартов используйте `os.MkdirTemp` и defer `os.RemoveAll`.

## 6. Используйте Values в виде map[string]interface{}
Не забывайте объединять пользовательские значения со значениями по умолчанию.

## 7. Для продакшена используйте TLS и аутентификацию
Kubeconfig должен быть настроен правильно, поддержка сертификатов обеспечивается стандартной конфигурацией.

## 8. Тестируйте с fake‑клиентом Kubernetes
```go
import "k8s.io/client-go/kubernetes/fake"
```
Используйте fake‑клиент при инициализации action.Configuration.

## 9. Логируйте операции
Передавайте кастомный логгер в `actionConfig.Init(...)`.

## 10. Следите за версией API Helm
Helm v3 регулярно обновляется, проверяйте совместимость с используемой версией.
