# Уровни логирования и фильтрация

## Установка общего уровня

```go
log.SetLevel(logrus.WarnLevel) // только Warn, Error, Fatal, Panic
```
На проде не включайте `Debug`/`Trace` без необходимости.

## Динамическое изменение уровня
```go
// через переменную окружения
lvl, _ := logrus.ParseLevel(os.Getenv("LOG_LEVEL"))
log.SetLevel(lvl)
```
## Разные уровни для разных destinations
Можно разослать логи разных уровней в разные места (файлы, сеть) через хуки (см. следующий раздел).

## Hook для фильтрации по уровню
Встроенная возможность `Levels()` у хука позволяет отправлять только ошибки в алертер, а всё остальное — в stdout.

## Подавление логирования
Иногда нужно отключить логирование для конкретного контекста (например, тесты). Используйте `log.SetOutput(io.Discard)`.

## Локальный logger с персональным уровнем
Создайте новый логгер с индивидуальной настройкой:
```go
appLogger := logrus.New()
appLogger.SetLevel(logrus.DebugLevel)
appLogger.SetOutput(os.Stdout)
```
